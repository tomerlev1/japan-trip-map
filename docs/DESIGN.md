# מסמך תכנון — מפת הטיול ליפן

## מטרה
מוצר-קצה יציב לשני מטיילים: מפה דינמית של המסלול היומי ביפן, עם עריכה קלה ושיתוף בין מכשירים, בלי שרת ובלי עלויות.

## החלטות מרכזיות
| נושא | החלטה | נימוק |
|---|---|---|
| סטאק | Vanilla JS + Leaflet, ללא build | אפס תלויות = אפס תקלות תחזוקה; טעינה מיידית |
| מפה | CARTO Voyager tiles | חינמי, מהיר, קריא, retina |
| אחסון | localStorage + share-link דיפים | אין backend; שיתוף = קישור קצר (gzip+base64url של ההבדלים בלבד) |
| פריסה | GitHub Pages | לא-מקומי, נגיש מכל מכשיר, גרסאות בגיט |
| קואורדינטות | ידני + אימות Photon/Nominatim | אטרקציות מפורסמות ידניות ומדויקות; מסעדות שלא אותרו מסומנות ≈ עם סיכה גרירה + ניווט לפי שם |
| RTL/עברית | מלא | קהל היעד |

## מודל נתונים
- `DAYS` — 17 ימים (d0 נחיתה … d16 טיסה), לכל יום: צבע, כותרת, תקציר, מלון, הערת מעבר, רשימת מזהי עצירות.
- `PLACES`/`COORDS` — 92 מקומות ברירת-מחדל.
- `CATALOG` — 97 מקומות נוספים להחלפות (מסעדות/ברים/אטרקציות מהחוברת).
- state המשתמש: `{v, dayStops, custom}` — סדר עצירות לכל יום + מקומות שנוספו/נערכו. ולידציה בכל טעינה/ייבוא/קישור.

## שינויים מול החוברת המקורית (שהתחילה 08.09)
- ימי טוקיו 1–3 המקוריים נדחסו ל-11–12.09 (ירד יום ההתאקלמות; הערב הראשון הוא ערב הנחיתה 10.09).
- DisneySea הוסר (נשאר בקטלוג אם מתחרטים).
- האקונה: לילה אחד — יום 11 (21.09) נסיעה + מוזיאון פתוח + גורה; יום 12 (22.09) אוואקודאני + שייט + מקדש, וחזרה לטוקיו בערב.
- 4 ימי טוקיו האחרונים נדחסו ל-3: רופונגי+Borderless+מגדל (23.09), שימוקיטזאווה+שינג'וקו (24.09), צוקיג'י+גינזה+Planets (25.09). אקיהברה שובצה כאופציית לילה ב-25.09 — קל להזיז.

## אבטחה ואיכות
- כל טקסט משתמש עובר escape (מניעת XSS גם דרך קישורי שיתוף).
- קישור שיתוף לא נטען אוטומטית — באנר אישור עם ציון מספר השינויים.
- בדיקות: `tools/validate.mjs` (שלמות נתונים) + בדיקת E2E ב-Playwright (רינדור, עריכה, undo, קטלוג, שיתוף בין שני דפדפנים) — עברו נקי.
