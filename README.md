# יפן 2026 · המפה שלנו 🗾

מפה אינטראקטיבית של מסלול הטיול ליפן (10–26.09.2026): טוקיו → קיוטו → אוסקה → נארה → האקונה → טוקיו.

## מה יש בה
- **מסלול יומי צבעוני** — לכל יום צבע משלו, עצירות ממוספרות לפי סדר הביקור, וקו שמחבר ביניהן.
- **פרטים לכל עצירה** — תיאור, חלק ביום, קישור למפות Google, ניווט בתחבורה ציבורית מהעצירה הקודמת, אתר רשמי ו-Klook (קוד OMERINJAPAN).
- **עריכה מלאה** — החלפת אטרקציה מתוך קטלוג של ~190 מקומות מהחוברת (מסעדות, ברים, אטרקציות), גרירה לשינוי סדר, הזזה בין ימים, הוספת מקומות חדשים.
- **שיתוף** — כפתור 🔗 יוצר קישור שמכיל את כל השינויים; פותחים אותו בכל מכשיר ולוחצים "טען גרסה זו".
- **גיבוי** — ייצוא/ייבוא לקובץ JSON, ביטול (Ctrl+Z) ואיפוס למסלול המקורי.
- **📌 רשימת הזמנות עם צ'קבוקסים** — כל מה שצריך להזמין מראש לפי ימים; מסמנים ✓ כשהוזמן, הכפתור בכותרת מראה כמה נשארו, והסימונים עוברים גם בקישורי השיתוף.
- **🗓 מצב "היום"** — בזמן הטיול האפליקציה נפתחת אוטומטית על היום הנוכחי (לפי שעון יפן), עם סימון "היום" בסרגל.
- **📍 מיקום חי** — כפתור GPS מציג אתכם על המפה (נקודה כחולה + דיוק) ביחס למסלול היום.
- **☁️ סנכרון חי (רדום)** — הקוד מוכן ונבדק; יופעל רק אם יחובר פרויקט Supabase ייעודי (ראו `tools/sync-migration.sql` + `js/config.js`). בלי חיבור — אין שום תעבורת רשת והכפתור מוסתר.

## מבנה הקוד
```
index.html          — שלד הדף (RTL, עברית)
css/style.css       — עיצוב, כולל מובייל
js/data.js          — נתוני המסלול: ימים, מקומות, קואורדינטות, קטלוג, טיפים
js/config.js        — הגדרות (חיבור סנכרון אופציונלי)
js/storage.js       — ניהול מצב: localStorage, undo, דיף-שיתוף (gzip+base64url), צ'קבוקסי הזמנות
js/sync.js          — סנכרון חי אופציונלי (fetch + polling, ללא ספריות)
js/app.js           — ממשק: מפה (Leaflet), פאנל ימים, קטלוג, עריכה, שיתוף
vendor/leaflet/     — Leaflet 1.9.4 (מוטמע, ללא תלות ב-CDN)
tools/validate.mjs  — בדיקת שלמות הנתונים
tools/geocode.mjs   — איתור קואורדינטות (Photon)
```

- אין build ואין תלויות — קבצים סטטיים בלבד. פריסה: GitHub Pages.
- שינויים נשמרים ב-localStorage של המכשיר; שיתוף מעביר רק את ההבדלים מהמסלול המקורי.
- מקומות עם מיקום משוער מסומנים ב-≈ — אפשר לגרור את הסיכה שלהם למקום המדויק, וקישורי הניווט שלהם משתמשים בשם (מדויק תמיד).

## עדכון המסלול הקבוע
עריכות בקישור/מכשיר הן אישיות. כדי לשנות את **ברירת המחדל לכולם** — לערוך את `js/data.js`, להריץ `node tools/validate.mjs` ולדחוף ל-main.
